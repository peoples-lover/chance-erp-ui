## 如何打开

**方式一（推荐）** —— 直接双击 `index.html`，任意现代浏览器即可运行，无需安装、无需联网、无需构建。

**方式二** —— 起本地服务（避免个别浏览器对 `file://` 的图片限制）：

```bash
cd "ERP/原型稿/prototype"
python3 -m http.server 8777
# 浏览器打开 http://localhost:8777
```

## 已落地的核心业务规则

**CP 公共库**

- OE 按来源折叠分组；同一 OE 在每个命中它的来源分组内**重复展示**，各自保留来源、可信度
- 【出现来源】列始终展示该 OE 命中的全部来源，**来源筛选只控制分组显隐，不截断标签**；当前分组来源蓝色高亮，其余灰色
- OE 品牌为必填字段（CH010），弹窗校验、导入模板、导出、报表全部对齐
- 四类 OE 关系严格区分：交叉引用 / 替代关系 / 同组关系 / 同功能关系，各带方向、适用条件、来源凭证、可信度、审批状态

**自有产品库**

- CP 引用编号与 OE 引用**只读展示，全站无任何跳转 CP 公共库的入口**
- 供应商下拉在【规格】与【图片】Tab **跨 Tab 同步**，均含「全部供应商」
- 切换供应商联动：主图切换 + 底部工厂标注 + 报价表过滤；无实拍图显示**系统默认负片**
- 报价维度 = SKU + 供应商，三色状态（有效 / 即将过期 / 已过期）由有效期实时计算，非写死
- SKU 私有交叉与 CP 全局交叉两套数据隔离，【参考 CP 全局交叉】只做勾选复制

**订单**

- 自动带出报价单价、MOQ、有效期、状态
- 数量 < MOQ：输入框**红色边框** + 红色告警文字；数量 ≥ MOQ 时红框与告警同时消失
- 报价已过期 → 橙色提示条；无有效报价 → 红色提示「暂无该供应商有效报价，请重新询价」
- 定制开关联动：定制差额输入框 + 订单定制图片上传，图片只存订单行，不回写产品图库
- 最终成本 = 报价单价 ± 定制差额；总金额 = 最终成本 × 数量；无权限时全部 `***` 且不计算

**权限与日志**

- 供应商代码全局唯一、全部角色可见、不受脱敏控制，作为单据与报表关联索引
- 脱敏只发生在展示层与导出层，数据库原始数据完整保存
- 两套日志分离：系统操作日志（自动、含变更前后快照、无需审核） vs 需求变更日志（人工提交、图片证明、审批）
- 审批权限隔离：提交人与审批人不能为同一人

## 相对原型文本的补充

原型文本（V-Full）以外，按《卡车配件ERP产品库设计》评审意见补充了以下 P0 项，均已在界面上体现：

1. **OE 标准化清洗规则** —— 转大写、去空格 / 横杠 / 点号；OE 列表展示标准化后的号码；系统设置 → 数据源配置中给出规则说明
2. **可信度 A/B/C/D 判定标准** —— 写入枚举配置与仪表盘图例，不再由产品人员主观判断
3. **四类 OE 关系** —— 原型文本只有「原厂交叉 / 工厂替代」两类，已扩展为设计文档要求的四类
4. **CP 覆盖状态** —— 未覆盖 / 已覆盖 / 部分覆盖，由自有库映射反向计算
5. **低可信度 OE 确认任务** —— 仪表盘任务看板，含触发询价单、确认对象、任务状态
6. **数据生命周期** —— 全站按钮文案统一为「停用 / 归档」，明确禁止物理删除
7. **审计快照** —— 系统操作日志记录变更前后值
